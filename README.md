**Speckl applications — the dark-factory portfolio**

A dark factory is a system where constraints are strict, feedback loops are tight or absent, and a human can't catch the bug. Speckl is the compile-time layer that bakes human judgment into the runtime so the dark factory inherits the taste instead of trying to interpret it. These seven repos are each a different dark-factory problem, specified in Speckl and compiled to four artifacts (TypeScript, PROV-O provenance, CycloneDX SBOM, SPDX snippet).

- **[speckl-kafka-kraft](https://github.com/wscoble/speckl-kafka-kraft)** — *flagship* — Kafka KRaft consensus protocol. Distributed-systems dark factory.
- [speckl-paxos](https://github.com/wscoble/speckl-paxos) — Paxos consensus. Byzantine-resilience dark factory.
- [speckl-raft](https://github.com/wscoble/speckl-raft) — Raft consensus. Leader-election dark factory.
- [speckl-banking-ledger](https://github.com/wscoble/speckl-banking-ledger) — Account ledger. Regulated-industry dark factory (HIPAA, audit, attestation).
- [speckl-clinical-dosing](https://github.com/wscoble/speckl-clinical-dosing) — Drug dosage calculator. Patient-safety dark factory (HIPAA, FHIR, Epic).
- [speckl-access-control](https://github.com/wscoble/speckl-access-control) — Access control. Auth/authz dark factory.
- [the-soil-beneath-the-code](https://github.com/wscoble/the-soil-beneath-the-code) — the book this thesis grew out of.
